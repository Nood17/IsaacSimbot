# lunar-grav-loco 研究路径

## 一句话目标

> **训练一个以重力为条件输入的单一 RL 运动策略，在月面重力（0.16g）到超重（2g）范围内连续泛化；配套开源 LunarLoco-Bench 评测基准；第二阶段接入 VLA 中层语言指令并研究重力偏移下的失效模式。**

## 产出规划（两篇论文）

| | 论文 1 | 论文 2 |
|---|---|---|
| 题目方向 | Gravity-Conditioned Locomotion + LunarLoco-Bench | VLA under Gravity Shift |
| 创新点 | 重力条件化单策略 + 步态相变分析 + 统一基准 | VLA 中层指令在低重力下的失效/修正 |
| 目标 | ICRA / IROS / RA-L | CoRL / RSS（或 workshop） |
| 性质 | 方法 + 实证 | 应用 + 分析 |

## 阶段路径

### M0 环境就绪（前置）
- [ ] 重启电脑，确认 `nvidia-smi` 正常（驱动 595.91.07）
- [ ] 安装 Isaac Sim 5.x + Isaac Lab（Isaac Sim 4.5/5.x 均可）
- [ ] 克隆 `unitreerobotics/unitree_rl_lab`，跑通 G1 默认 velocity 任务（地球重力）作为 sanity check
- 备选：无 GPU 时先用 `unitree_mujoco` Python 版跑通流程

### M1 基线复现（对标 QUT 工作）
- [ ] 在 unitree_rl_lab 中将 g 改为 1.62 m/s²，训练 G1 月面行走
- [ ] 三策略对比复现：Earth 基线 / 月面 fine-tune / 月面从零训练
- [ ] 验证文献中的步态涌现：短步幅、前掌着地、质心前移
- 产出：跑通的训练管线 + 基线数据（这一步本身就是论文1的 baseline）

### M2 核心方法（论文 1 主体）
- [ ] 观测向量注入归一化重力 `g/g_earth`；重力值逐 episode 随机化 ∈ [0.16g, 2g]
- [ ] 重力缩放能耗奖励（参考 Arm et al. arXiv:2509.10128）
- [ ] 关键对比实验：条件化单策略 vs per-gravity 独立策略 vs fine-tune vs zero-shot
- [ ] 步态相变分析：g-v 平面 gait map（什么重力下策略从走切换到跳？）
- 产出：`sections/method.md` + `sections/experiments.md` 初稿

### M3 LunarLoco-Bench 封装（论文 1 的评测载体 + 开源影响力）
- [ ] 任务集：平地行走 / 坡面 / 台阶 / 跳跃 / 外力扰动恢复
- [ ] 重力档位：0.16g(月) / 0.38g(火星) / 1g(地球) / 1.5g / 2g
- [ ] 统一指标：CoT、速度跟踪误差、跌倒率、关节峰值扭矩、恢复时间
- [ ] 开源发布（GitHub + 文档）→ workshop 投稿素材
- 产出：可复用评测协议（也服务 M4）

### M4 VLA 接入（论文 2）
- [ ] NaVILA 式分层：小型量化 VLM（4-8B）输出中层语言动作 → 你的重力条件化低层策略执行
- [ ] 失效模式分析：重力偏移下中层指令语义是否漂移？（"跳2米"在月球多跳多远？）
- [ ] 修正方法：重力感知的中层动作缩放 / 条件化重校准
- 产出：论文 2

## 关键风险与对策

| 风险 | 对策 |
|---|---|
| 8GB 显存跑不动大并行 | 降 num_envs 到 1024-2048；G1 29dof 比 Go2 12dof 更吃显存，必要时先用 Go2 验证再迁 G1 |
| 条件化策略学不会步态切换 | 先离散条件（3 档重力）验证可行性，再连续化 |
| Isaac Sim 安装坑 | Ubuntu 26.04 很新，装不上就退回 MuJoCo 路线（unitree_mujoco + 自写 RL） |
| 创新性被抢先 | 每 2 周跑一次 S2/arXiv 检索 `gravity conditioned locomotion` 监控 |
