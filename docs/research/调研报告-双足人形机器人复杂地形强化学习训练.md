# 双足人形机器人复杂地形强化学习训练 — 调研报告

> 目标：在仿真环境下训练双足人形机器人完成复杂地形行走这一较难任务。
> 覆盖：训练方法与场景、可参考项目与比赛、训练技巧与常见坑、训练策略、**训练失败的诊断与恢复**。
> 与四足版本对照阅读：人形难度显著更高——支撑面小、自由度多、摔倒代价大、sim2real gap 更大。

---

## 0. 总体训练方法与技术栈

### 0.1 仿真器/框架选型

| 方案 | 状态 | 说明 |
|---|---|---|
| **Isaac Gym + humanoid-gym 系** | ⚠️ 已废弃但资料多 | 人形 RL 爆发期（2024–2025）大量开源项目基于此；RTX 40/50 系跑不了，仅用于读代码 |
| **Isaac Sim + Isaac Lab** | ✅ 主流 | 官方有 `Isaac-Velocity-Flat/Rough-G1/H1` 任务；Berkeley Humanoid、Booster 官方迁移至此 |
| **MuJoCo + mjlab / unitree_rl_mjlab** | ✅ | 宇树 G1/H1_2/R1 已支持；sim2sim 验证必经环节 |
| **Genesis** | ✅ | HumanoidVerse 支持；仿真速度极快 |
| **多仿真框架 HumanoidVerse** | ✅ 推荐对比实验 | 一条命令切 IsaacGym/IsaacSim/Genesis：`+simulator=<name>` |

**机器人选型**：
- **Unitree G1（23/29 dof）**：生态最全（unitree_rl_lab、HumanoidVerse、legged_rl_lab、ProtoMotions 全支持），实机便宜且比赛多。
- **Booster T1**：booster_gym/booster_train 全链路，足球赛明星机型。
- **Berkeley Humanoid**：论文级精简管线（轻 DR + 简单 RL 就上了野路），Isaac Lab 代码开源。

### 0.2 标准流水线

```
运动数据重定向（可选）→ Train（headless, 4096 envs, PPO）
  → Play → Sim2Sim（MuJoCo/IsaacSim/Genesis 交叉验证）
    → Sim2Real（ONNX/JIT 导出 → deploy 框架 → 实机）
```

### 0.3 算法与动作空间

- **PPO + rsl_rl** 仍是绝对主流。**别换算法**——人形的瓶颈是工程不是算法。
- 动作空间：**PD 关节位置目标**为主流（策略 50–100Hz，PD 1kHz）；进阶做法让策略同时输出**腿部 PD 增益**（Science Robotics 2024）；脚趾等不重要关节可直接固定默认位置。
- 超参与四足的差异：**熵系数 0.008（比四足 0.01 低）**——双足平衡余量小，需要更确定的动作；`init_noise_std` 1.0；`desired_kl` 0.01。
- **相位时钟观测是人形标配**：`[sin(2πt/C_T), cos(2πt/C_T)]` 进观测，配合**周期性触地掩码奖励**（见 2.2）。

### 0.4 场景难度分级

1. **站立**（站稳本身就是任务——人形必须先过这关）
2. **Flat**（速度跟踪）
3. **Rough / Slopes**（1–6cm 噪声、0–17° 坡）
4. **Stairs**（上下楼梯——单支撑期是难点）
5. **跳跃/摔倒恢复/踢球**（离散大动态技能）
6. **全身动作模仿**（舞蹈、空翻——AMASS/mocap 驱动）

### 1.3 关键论文方法谱系

| 方法 | 核心思想 |
|---|---|
| **Periodic Reward Composition**（Siekmann 2021, Cassie） | 双足步态 = DS/SS 触地时间表 + 每相足端力/速度目标；参考轨迹无关的步态规格化奖励 |
| Science Robotics 2024（全尺寸人形） | 生物力学启发奖励（不用步态库）；**teacher KL 监督随训练退火到 0**，学生最终可超越 teacher |
| **ASAP**（2025, CMU） | ⭐ 两阶段弥合 dynamics mismatch：仿真预训跟踪策略→实机采数据训 **delta action 残差模型**→把残差模型放回仿真器微调策略。解决 DR/SysID"要么保守要么调参地狱" |
| **OmniH2O**（CoRL 2024） | 运动学姿态为通用接口：VR 遥操/语音/RGB；特权 teacher→DAgger 蒸馏 student；含 OmniH2O-6 数据集 |
| **ExBody2** | 局部坐标系关键点跟踪 + 速度控制**解耦**，解决全局关键点跟踪一步错步步错 |
| **GMR / "Retargeting Matters"**（2025） | 重定向质量直接决定策略上限：foot sliding/自穿插/物理不可行的参考轨迹会显著拉低鲁棒性 |
| **D-PPO（蒸馏-PPO）** | teacher 权重直接继承给 student + 蒸馏损失与 PPO 损失各半混合继续训，比纯蒸馏抗噪、比纯 RL 好训 |
| **HiFAR** | 摔倒恢复多阶段课程——人形特有的必备技能 |
| **TOLEBI** | 容错双足：在线关节状态估计 + fallibility 奖励（减小故障脚接触力） |
| **RoboNaldo** | 运动引导课程：单条人踢参考 → 定点任意球 → 运动球射门，G1 实机球速 13m/s |
| AGILE（2026） | 人形 RL 全生命周期工作流：环境验证→可复现训练→统一评估→描述符部署 |

## 2. 训练技巧与常见坑

### 2.1 观测设计（人形特有）

- 标配本体感知之外，**相位时钟 [sin,cos] 几乎必加**（humanoid_gym、大多数 framework 都内置）。
- 足端接触状态 `I_d(t)`、期望触地掩码 `I_p(t)` 进观测/特权观测。
- 上身自由度多时：手臂关节观测可以降采样或固定，先训腿。
- 观测历史帧堆叠同样适用（非 Markov 杀手）。

### 2.2 奖励设计（人形特有项）

在 legged_gym 经典配方基础上，人形必须加/调：

```python
# 步态周期类（核心差异！）
feet_contact_schedule   # 按 DS/SS 相位掩码奖励/惩罚对应脚的接触
feet_swing_height       # 摆动期抬脚高度目标（正弦参考）
feet_orientation        # 脚掌平行地面，防脚尖拖地
knee_direction          # 膝盖朝向约束
step_width / feet_distance  # 步宽约束，防交叉步
hip_pos / ankle_torque  # 髋、踝特化项

# 双足特有正则
feet_stumble / feet_edge
arm_swing / upper_body  # 摆臂协调（可选，先冻结也能走）
```

- **周期性奖励组合**（Periodic Reward Composition）：不给整条参考轨迹，只给"哪个相位哪只脚该接触/施加多少力/摆多快"——既规格化步态又不限制环境适应。
- **惩罚量要软着陆**：iScience 实验——初始就给强能耗惩罚 → 策略收敛到"零动作"假死；用**约束优化/自适应权重**而非固定大权重。
- `rel_standing_envs≈0.02`：留一小撮零速环境专练站立。

### 2.3 域随机化（人形范围比四足更保守起步）

- 人形先窄后宽：摩擦 0.5–1.0 起步再扩；质量 ±5kg；推力 5–10s 间隔。
- **电机模型更重要**：人形膝/踝在单支撑期接近力矩极限，热降额、限流会真机暴雷——`armature`/电机强度随机化 + actuator net。
- 自碰撞：`self_collisions` 人形必须更小心（腿长易扫到一起），但**全关会学出穿腿步态**——只关非必要对。

### 2.4 课程学习（人形版）

1. **先关所有课程！** 人形初期连站立都难——开课率后所有 env 挤在最简单地形，永远学不到难地形。经验：**平地站走稳 → 再开地形课程**。
2. 地形网格 4 级起步：flat 25% → rough 1–6cm 25% → 坡 0–17° 25% → 楼梯。
3. 速度阶梯课程：平地基线跑稳后只扩 `lin_vel_x` 范围，**跑速可以零修改自然涌现**（yanshi-rl-lab 实测 4m/s）。
4. 摔倒恢复单独成课（HiFAR 分阶段）。
5. 奖励权重课程：站立期先给姿态/高度正奖励，走稳后逐步转移权重到 tracking。

### 2.5 人形特有坑

- **接触误判**是最常见实机/仿真 bug 源：脚尖扫地、脚跟先落被误判为稳定支撑 → 重心崩。加接触迟滞（连续 N ms 有力才算触地）。
- **时钟不同步**：观测/控制/接触判断错几毫秒，切支撑附近就随机崩。
- **关节零位/rigging**：Isaac Lab 文档反复强调 joint mismatch 直接异常行为。
- **热降额/限流**：走一会儿才崩先查母线电压和温度，别先改增益。
- **单支撑期力矩饱和**：膝踝关节接近饱和时摆脚慢半拍——摆脚高/步长别一把拉大。
- 并联腿部结构（Booster T1 等）需要特殊处理——booster_gym 有现成方案。
- **摔倒成本**：人形摔倒比狗严重得多（胳膊手肘都可能坏）。仿真里练**摔倒恢复**是刚需不是选修。

## 3. 训练策略（按难度递进）

### 3.1 速度跟踪盲策略——基线
PPO + 相位时钟 + DS/SS 触地奖励 + 地形课程（后期开）。站稳→平地走→粗糙走。

### 3.2 Teacher-Student 蒸馏——地形感知标配
- 标准两阶段（特权 teacher → 历史观测 student，DAgger）
- **D-PPO 改良**：student 直接继承 teacher 权重 + 混合损失继续 RL，可超越 teacher。
- **KL 退火变体**（Science Robotics 2024）：蒸馏权重 λ 从中途线性退到 0。

### 3.3 动作模仿路线——人形的主干道（比四足更重要）

人形有天然优势：**海量人类动捕数据**（AMASS、LAFAN1）。

```
动捕数据 → 重定向到机器人（GMR/ProtoMotions PyRoki）
  → 运动跟踪策略（DeepMimic 式 / PHC / AMP 风格奖励）
    → 速度/指令控制接口（ExBody2 解耦关键点+速度）
      → sim2real（ASAP delta action / DR / SysID）
```

- 重定向质量决定上限：脚滑、自穿插的参考轨迹会直接降低策略鲁棒性（Retargeting Matters）。
- AMP 在人形上同样有效：判别器风格奖励替代手工奖励。
- 先训**通用跟踪策略**再蒸馏到任务策略（ProtoMotions 模式），比从零训任务效率高一个量级。

### 3.4 分层与技能组合

- 低层：运动跟踪/步态策略；高层：速度指令/技能调度/规划器。
- 技能原语（RoboCup FC Portugal 思路）：walk/kick/push 各自成技能 + 统一接口。
- 摔倒恢复策略与行走策略**并列部署**，状态机切换。

### 3.5 Sim2Real 专门策略

| 方法 | 说明 |
|---|---|
| 重 DR | 经典但易保守 |
| SysID + 中 DR | Berkeley Humanoid 路线：硬件设计时就压 gap，轻 DR 就够 |
| **ASAP delta action** | 实机数据训残差动作模型回灌仿真器，微调策略——保持敏捷性 |
| actuator net | 电机非线性建模 |

### 3.6 建议落地路线

1. Isaac Lab 官方 `Isaac-Velocity-Flat-G1` 跑通；再跑 rough。
2. 上 HumanoidVerse/unitree_rl_lab：站稳 → 平地走 → 地形课程逐步开。
3. 接相位时钟 + 触地掩码奖励，对照 humanoid-gym 论文。
4. 复杂地形：teacher-student 或 D-PPO。
5. 进阶：ProtoMotions 重定向一条 AMASS 轨迹训跟踪策略 → 体会模仿路线。
6. 挑战：楼梯/沟壑 + 摔倒恢复；有余力上 ASAP 式实机对齐。

## 4. 训练失败的诊断与恢复（人形版）

> 人形特有规律：**一切从"能不能站稳"开始**。站不稳的策略什么都学不到。

### 4.1 排查层级（自底向上）

1. **资产/驱动层**：关节零位与 rigging（joint mismatch 直接崩）、PD 增益、`ImplicitActuatorCfg` vs `DCMotorCfg`、**自碰撞配置**（人形腿易互扫，全关会穿腿）、并联结构是否处理。
2. **接触层**：接触判定迟滞、鞋底碰撞体（capsule 替代）、摩擦设定。
3. **奖励层**：符号门控、相位掩码是否对齐参考时钟、`only_positive_rewards`。
4. **学习层**：熵 0.008、噪声、KL。

**黄金法则**：**先关课程训平地站立**。站都站不稳 → 配置问题；站得稳走不好 → 奖励/探索问题；平地能走 rough 崩 → 课程/难度问题。

### 4.2 典型失败模式 → 应对

| 症状 | 根因 | 解法 |
|---|---|---|
| **零动作瘫站/罚站** | 能耗/惩罚初始权重过大；摔倒惩罚下"不动最安全" | 能耗惩罚用自适应权重（初期近 0）；先姿态正奖励+站立课程；`alive` 奖励+`stand_still` 罚组合 |
| **刚迈步就倒** | 相位时钟缺失或掩码不对齐；动作幅度大 | 加 [sin,cos] 时钟 + DS/SS 掩码奖励；降 action_scale；冻结手臂先训腿 |
| **脚尖拖地绊倒** | 摆动期抬脚不够；脚掌姿态歪 | `feet_swing_height` 正弦目标；`feet_orientation` 惩罚；`feet_stumble` |
| **原地抖腿/抽搐** | action_rate/dof_acc 罚太轻；时钟没进观测 | 加平滑项；确认时钟观测在 actor 输入里 |
| **左右步态不对称** | 无对称约束，探索收敛到歪步态 | rsl_rl `symmetry_cfg` 镜像增广（人形收益更大） |
| **单支撑期崩** | 切支撑瞬间被误判/力矩饱和 | 接触迟滞；踝膝限力放宽；DS→SS 过渡区加接触奖励宽容度 |
| **上楼梯学不会** | 课程跳级；抬脚高度不足 | 地形课程降级重训；楼梯单独里程碑（先矮阶） |
| **仿真能走真机秒倒** | sim2real gap 比四足大一个量级 | sim2sim 先过 MuJoCo；ASAP delta action；电机/摩擦/延迟 DR 加宽 |
| **摔倒后爬不起来** | 没训恢复 | HiFAR 分阶段恢复课程单独训，运行时状态机切换 |
| **奖励涨到一半崩** | policy collapse | 降 lr/clip；查 KL、explained_variance；dense+sparse 混合 |

### 4.3 人形特有的"救命稻草"（按见效速度排序）

1. **冻结上半身**：先只训腿（或锁手腕/肘部自由度），走稳再放开——DOF 越少越好学。
2. **相位时钟 + 触地掩码**：人形步态几乎是必需品，缺了它 PPO 在双足上搜索空间太大。
3. **参考正弦步态 / RSI**：给了先验就从"能走的点"倒着学。
4. **Residual RL**：WBC/MPC/正弦步态做基底 + 残差修正。
5. **动作模仿先验**：一条重定向的走路 mocap 就能当 AMP 风格奖励来源。
6. **Teacher-student**：特权 critic/teacher 都能显著降难度。

### 4.4 监控什么

- `rew_*` 分项 + `contact_schedule` 命中率（期望接触 vs 实际）。
- `mean_episode_length`：人形摔倒非常早，episode 长度是最敏感指标。
- 左右脚腾空时间对称性。
- `explained_variance`、KL、entropy/std。
- **必须定期 play 看视频**——人形步态缺陷（拖脚、内八、含胸）曲线看不出来。
- 评估指标向 ICRA 对齐：MTBF（平均无摔倒间隔）、多地形通过率、抗推恢复率。

### 4.5 决策树

```
站都站不稳 → 资产/零位/自碰撞/接触判定（4.1 层）
站得稳不走 → 相位时钟 + DS/SS 掩码奖励 + 站立课程
走得动但老摔 → 接触迟滞 + 踝膝力矩检查 + 对称增广
会走平地上不了坡/楼梯 → 地形课程降级 + RSI + teacher-student
步态丑/拖地 → feet_swing_height/feet_orientation/feet_stumble
奖励越调越乱 → 分层渐进 or 转模仿路线（AMASS 重定向 + AMP/跟踪奖励）
真机部署 → 先 sim2sim → ASAP delta action
```

## 5. 人形 vs 四足：核心差异速查

| 维度 | 四足 | 人形 |
|---|---|---|
| 天然稳定性 | 高（四点支撑） | 低（单/双支撑交替） |
| 站立 | 免费 | **本身就是任务** |
| 熵系数 | 0.01 | 0.008（更需确定性） |
| 相位时钟 | 可选 | **几乎必需** |
| 触地掩码奖励 | 可选（feet_air_time 够） | **核心**（DS/SS 调度） |
| 探索空间 | 12 dof | 23–29 dof（先冻上身） |
| 摔倒代价 | 低 | 高（手肘/头都可能坏）→ 恢复技能刚需 |
| 模仿数据 | 狗动捕少 | **AMASS 海量人数据** |
| sim2real gap | 中 | 大（热降额、并联结构、单支撑饱和） |
| 课程策略 | 地形课程早开 | **先关课程站稳，再逐级开** |
| 分层需求 | 异构地形才需要 | 行走+恢复+技能调度常态分层 |
