# 四足机器狗复杂地形强化学习训练 — 调研报告（v2）

> 目标：在仿真环境下训练四足机器人完成复杂地形行走这一较难任务。
> 覆盖：训练方法与场景、可参考项目与比赛、训练技巧与常见坑、训练策略、**训练失败的诊断与恢复**。

---

## 0. 总体训练方法与技术栈

### 0.1 仿真器/框架选型（先定这个）

| 方案 | 状态 | 说明 |
|---|---|---|
| **Isaac Gym (Preview) + legged_gym** | ⚠️ 已废弃 | 经典组合（ETH RSL），海量论文和比赛代码基于此。**不支持 RTX 40 系及更新显卡**（nvrtc `--gpu-architecture` 报错），官方不再维护，只适合复现旧代码 |
| **Isaac Sim + Isaac Lab** | ✅ 主流推荐 | Isaac Gym 官方继任者，PhysX + GPU 并行，内置 locomotion 任务、Manager-Based 抽象、地形生成器、RSL-RL/SB3/skrl/rl_games 接口 |
| **MuJoCo + mjlab / MuJoCo Warp** | ✅ 新趋势 | mjlab 把 Isaac Lab API 风格搬到 MuJoCo（GPU 加速），轻量适合 sim2real 验证；宇树官方 `unitree_rl_mjlab` 已支持 Go2/A2/G1/H1 等 |
| **Genesis** | 可选 | 新兴 GPU 物理引擎，社区有四足示例 |

**建议**：新项目直接用 **Isaac Lab + RSL-RL (PPO)**；机器人选 **Unitree Go2**（生态最全、比赛最多、部署资料最全）。

### 0.2 标准流水线

```
Train（Isaac Lab, --headless, 1024–4096 envs）
  → Play（可视化验证）
    → Sim2Sim（MuJoCo/unitree_mujoco 再验证一遍，抓 sim 内禀 bug）
      → Sim2Real（ONNX/JIT 导出 → 实机部署，FSM 安全保护）
```

### 0.3 算法选择

- **PPO（rsl_rl 实现）是绝对主流**——几乎所有 legged_gym/Isaac Lab 四足项目都用它。**不要换算法**：腿足 RL 的核心挑战在工程（奖励设计、DR、仿真精度、部署链路），PPO 在所有 SOTA（ANYmal Parkour、Walk These Ways、RMA）中表现已足够好。
- 典型超参：clip 0.2、GAE λ=0.95、γ=0.99、lr 1e-3 (Adam, adaptive)、熵系数 0.01（四足）/0.008（人形）、`desired_kl` 0.01、`init_noise_std` 1.0。
- **非对称 Actor-Critic**：critic 吃特权观测（真实地形、摩擦），actor 只吃可部署观测——几乎零成本的提升。
- 其他：SAC（SoloParkour 第二阶段从像素学习时用）、RND（rsl_rl 内置 `rnd_cfg` 探索扩展）、对称性扩展（`symmetry_cfg`）。

### 0.4 场景难度分级（任务递进）

1. **Flat**（平地速度跟踪）——验证管线
2. **Rough**（粗糙地形/斜坡/离散障碍，heightfield）——核心场景
3. **Stairs**（楼梯上下）——需要抬腿高度与落点
4. **Discrete/Parkour**（梅花桩、沟壑、高台跳、独木桥）——最难，需跳跃/爆发
5. **Vision**（深度相机替代 scandots）——真正端到端

## 2. 训练技巧与常见坑

### 2.1 观测设计

- **本体感知标配**：projected gravity、base lin/ang vel、关节 pos/vel、last action、速度指令。
- **地形感知**：机身周围高度采样网格（scandots/`measured_points`）；过梅花桩类地形**把采样点向前延伸**（看到对岸而不是身后深渊）。
- **非 Markov 是隐性杀手**：观测不含历史导致最优动作依赖不可见状态 → 纯 MLP 会平台化。对策：**N 帧观测历史堆叠**、足端接触标志、地形类别 one-hot，或循环网络。
- **特权观测喂 critic**（非对称 AC）。

### 2.2 奖励设计

legged_gym 经典配方：

```python
tracking_lin_vel = 1.0    # 任务奖励：速度跟踪（exp kernel）
tracking_ang_vel = 0.5
lin_vel_z       = -2.0    # 惩罚竖直蹿跳
ang_vel_xy      = -0.05   # 惩罚侧倾
torques         = -1e-5   # 能耗
dof_acc         = -2.5e-7 # 平滑
feet_air_time   = 1.0     # 鼓励腾空步态、防拖地
collision       = -1.0    # 机身碰撞
action_rate     = -0.01   # 防高频抖动
```

- **调参纪律：一次只改 1–2 个权重**，TensorBoard 盯分项 `rew_*` 曲线。
- `only_positive_rewards=True` 避免"早死早超生"；`send_timeouts` 让 PPO 对 timeout 做 bootstrap。
- 步态质量项：`feet_gait`（对角腿同步）、`feet_slide`（防滑）、`feet_stumble`（防绊）、`feet_edge`（桩边缘惩罚）、`foot_clearance`（抬腿高度整形，指数核 + 摆动相门控 + 移动门控）。

### 2.3 域随机化

- 常随机项：摩擦 0.2–1.5、质量/CoM、外力推搡 ±0.5~1.5m/s、电机强度/PD 增益、关节摩擦、观测噪声、延迟。
- **经验法则**：太少→过拟合仿真；太多→学不动甚至损害已学策略（zanshi-dev 实测：DR 直接注入使 fall_rate 升至 13%，需同时降低 PPO 更新强度）。
- 电机模型不匹配是 sim2real 头号死因：actuator net 或加大电机参数随机化。

### 2.4 课程学习（三层 + 两种打法）

1. **地形课程**：网格（行=难度、列=类型），走过半程升级、低于指令一半降级。
2. **指令课程**：跟踪好→扩大速度指令范围。注意 Isaac Lab 设 `rel_standing_envs≈0.02` 让 2% 环境发零速指令学会站立。
3. **奖励权重课程**：如竖直速度惩罚 -2.0→0、高度惩罚渐强。
4. **分阶段里程碑**（超难地形）：梅花桩案例——能到桩前→简化桩跳一下→跳两下→跳全部→走全程；必要时**先改地形**（加大桩面、统一桩高）再还原。
5. **自动课程**：TACL（评估器学难度函数，自动出题，比无课程成功率 +56%）。

### 2.5 常见坑清单

- Isaac Gym 在 RTX 40/50 系跑不了 → 用 Isaac Lab。
- `--headless` 提速显著；env 数过大有边际收益递减。
- 终止条件：base 触地终止 + timeout 分开；`terminate_after_contacts_on` 别漏配。
- 碰撞体：`replace_cylinder_with_capsule`；`enabled_self_collisions=False`（Isaac Lab Issue #458：自碰撞开错会导致策略站住不动！）。
- 自定义机器人资产：PD 增益、`ImplicitActuatorCfg` vs `DCMotorCfg`、URDF→USD 转换质量是新人最大坑源。
- 多地形单策略互相干扰 → 见 3.3。
- 至少跑 **3 个 seed** 再下结论。
- 模型选择看**留出地形上的表现**，不看最高训练奖励。

## 3. 训练策略（按难度递进的打法）

### 3.1 盲策略——第一站
PPO + 地形课程 + DR，本体感知（+scandots）。覆盖 flat→rough→stairs。

### 3.2 特权学习/蒸馏——复杂地形标配
- 两阶段 teacher-student（Lee 2020、Extreme Parkour）
- 单阶段：DreamWaQ/RMA/ROA

### 3.3 分层/多技能——对付异构地形
- **专家 + 切换器**：每地形一专家，上层按类别调度（梅花桩实战方案，最稳）。
- **MoE / 条件化**：PPO+MoE+CTS；MoB 步态参数条件化。

### 3.4 视觉端到端——最终形态
scandots→深度相机：特权 teacher 蒸馏视觉 student（Extreme Parkour）；或受限 RL 直接从像素学（SoloParkour）。

### 3.5 建议落地路线

1. 装 Isaac Lab → 跑官方 `Isaac-Velocity-Rough-Anymal-C` / unitree_rl_lab Go2 rough。
2. 自定义地形网格 + 地形课程 + 调奖励，3 seeds 对比。
3. 加 scandots + 特权 critic → teacher-student → DR 消融。
4. 梅花桩/沟壑（分阶段课程 + 分层策略兜底）→ 深度视觉。
5. sim2sim 到 MuJoCo；目标实机则走 unitree_mujoco → Go2。

## 4. 训练失败的诊断与恢复 ⭐（新增专题）

> 场景：奖励设计不优 / 任务过难 / 训练停滞 / 局部最优。
> 来源：Isaac Lab GitHub Issues、CSDN/知乎/技术博客实战帖、DeepMimic/AMP 论文、rsl_rl 源码。

### 4.1 第一步：分清"配置错误"还是"学习问题"

**排查层级（自底向上）：**

1. **资产层**：PD 增益、`default_joint_angles` 是否平衡姿态、URDF→USD 转换质量、`ImplicitActuatorCfg` vs `DCMotorCfg`、接触传感器是否配了不存在的 link、`enabled_self_collisions`。
   - 📌 案例：solo12 站着不动，原因是 `enabled_self_collisions` 开错（IsaacLab Issue #458）。
   - 📌 案例：自定义狗一出生就乱蹬触发 reset——actuator 配置错（IsaacLab Discussion #3789）。
2. **奖励符号/门控层**：`feet_air_time` 是否低速也发奖（要 `moving` 门控）；`tracking` 奖励用没用 exp kernel；`only_positive_rewards` 是否打开。
3. **学习层**：熵系数、噪声标准差、KL、学习率是否合适。

**黄金排查法则**（jishuzhan/技术栈实战经验）：**先关课程、先在平地训练**。若平地都学不会 → 基础配置问题；平地能学、rough 学不会 → 难度/探索问题。

### 4.2 典型失败模式 → 应对策略

| 症状 | 根因 | 解法 |
|---|---|---|
| **站着不动（最常见局部最优）** | 零动作天然稳定；惩罚总和 > 跟踪奖励；速度-稳定性冲突 | ①提高 tracking 奖励或降低惩罚权重 ②`stand_still` 惩罚 + `rel_standing_envs≈2%` ③**Residual RL**（参考 trot/CPG 兜底，策略只学残差——zanshi-dev 实测纯 PPO 失败→残差 PPO 达 0.3m/s） ④RSI |
| **疯狂抽搐然后摔** | 动作幅度太大；初始姿态不平衡 | 降低 `action_scale`（如 0.05）；提高生存/高度奖励权重先学会站；检查 `default_joint_angles` |
| **翘腿/原地踏步** | `feet_air_time` 权重过高或没门控 | 降权重（1.0→0.5/0.25/0.1）；提高触发门槛（clamp 到合理区间）；低速/零速关闭该项 |
| **蹬边缘借力跳一下走不完** | reward hacking | 地形边缘检测 + `feet_edge` 惩罚；改地形先简化再还原 |
| **前进就摔 / 稳定就停** | 速度-稳定性目标冲突 | 分层渐进开奖励（先基础跟踪，再逐步加步态质量项）；调 tracking_sigma；MoB 步态条件化 |
| **奖励曲线涨到一半崩** | policy collapse（PPO 大步更新把已学技能打没） | 混合 dense+sparse 奖励；降学习率/clip_param；查 KL 与 explained_variance；加 entropy 防过早收敛 |
| **多地形互相干扰** | 单网络容量/梯度冲突 | 分层专家切换；PPO+MoE+CTS；条件化地形 one-hot |
| **DR 一上就退化** | 随机化范围太宽吞掉有效梯度 | 收窄范围；同步降 PPO 更新强度（lr、epochs）；DR 也走课程（从小到大） |

### 4.3 奖励函数的"正确姿势"

**分层渐进法**（CSDN/知乎一致经验）：
- 先只开：生存/高度 + 速度跟踪 → 能勉强走
- 再逐个加：平滑（`action_rate`、`dof_acc`）→ 步态质量（`feet_air_time`、`feet_slide`、`feet_gait`）→ 能耗（`torques`）
- 每次加一个、跑一段、看分项曲线再决定下一步。

**理论上保险的整形：PBRS（势能奖励整形）**
- `F = γΦ(s') − Φ(s)` 形式的整形**不改变最优策略集**（Ng 1999；PBIM/GRM 扩展到内在动机）。
- 实践含义：想加"朝向目标""接近障碍中心"这类引导时，写成差分形式而非绝对值，避免引入假的吸引子。
- 相关的"reward shifting"技巧：线性平移奖励 = 改 Q 初始化；**负平移→好奇探索，正平移→保守利用**。

**替代方案：用数据替代手工奖励 —— AMP**
- Escontrela 2022 *Adversarial Motion Priors Make Good Substitutes for Complex Reward Functions*：判别器从**几秒真实狗（德国牧羊犬）动捕**学风格奖励，直接 sim2real，步态自然且节能，免去繁琐手工调参。
- 前置选项：DeepMimic 式跟踪奖励（相位同步 + 关节角误差）；IIT basic-locomotion 已集成 AMP。

### 4.4 探索不足 / 局部最优的专用武器

| 技巧 | 原理 | 何时用 |
|---|---|---|
| **RSI（参考状态初始化）** | 初始状态从参考轨迹均匀采样，"从终点倒着学"，破解"学不会第一步就永远到不了高奖励区"的鸡生蛋问题 | 跳跃、后空翻、梅花桩等**有明确成功状态**的任务；wbc-mjlab 还支持按失败率自适应分 bin 采样 |
| **ET（早终止）** | 摔倒/躯干触地立即终止，不让策略在失败态里学到恢复歪招 | 几乎总开；配合 termination penalty |
| **TC（终止课程）** | 终止阈值随训练放宽 | 高难度动态技能 |
| **Residual RL** | 手写 trot/CPG 做基底，网络只学残差修正 | 纯端到端探索不动时最立竿见影 |
| **对称性增广 / mirror loss** | 左右镜像的观测-动作对加入 batch 或做一致性损失 | rsl_rl `symmetry_cfg` 内置；四足天然对称，几乎免费提升步态质量 |
| **RND / 好奇心** | 对未见过状态给内在奖励 | rsl_rl `rnd_cfg` 内置；稀疏奖励/探索死局时 |
| **熵/噪声调高** | `entropy_coef` 四足 0.01（比人形 0.008 高，四足天然稳定需更多探索）；`init_noise_std` 1.0 起步 | 动作分布过早坍缩 |
| **多 seed + 选 checkpoint** | 单 seed 噪声大；选留出地形上最好的而非奖励最高的 | 永远 |

### 4.5 监控什么（别只看总奖励）

- `rew_*` 各分项：判断是哪一项在涨/在骗分。
- `mean_episode_length`：掉下来=摔得早；贴近上限=活着但可能不动。
- `terrain_level` / `max_command_x`：课程是否推进。
- `entropy` / `std`：持续下降→探索坍缩；暴涨→不稳。
- `explained_variance`（critic）：≈0 说明价值函数没学到，优势信号是噪声。
- **每隔几百 iter 用 play.py 肉眼看一次**——曲线会骗人，视频不会。

### 4.6 一句话决策树

```
平地都学不会 → 查资产/驱动/接触（第 4.1 层）
平地能学、复杂地形停滞 → 地形课程 + RSI + 分层课程
会走但步态丑/抖动 → 对称增广 + feet_slide/air_time 门控 + action_rate
站立不动假收敛 → Residual RL / RSI / stand_still + rel_standing_envs
跳跃类高难度 → RSI + 分阶段里程碑 + teacher-student 蒸馏
奖励越调越乱 → 回到分层渐进，或用 AMP/模仿先验替代手工奖励
```
