```

│   ├─ B2. 高保真月面仿真器（OmniLRS、Isaac Sim 生态）

│
├─ C. 学习控制方法（针对低重力的特化）
```

## 三、研究空白与机会点（🔥 = 热点，🕳 = 空白）

1. 🔥 **低重力步态涌现分析**：什么奖励/课程/观测让策略自主发现"跳跃优于行走"？ETH 能耗缩路线刚起步。
2. 🕳 **软月壤 + RL 联合训练**：几乎所有工作假设刚性接触；2606.10273 证明软接触改变步态且刚接触策略迁移失效——**结合可变形地形仿真的端到端训练是大空白**（算力瓶颈正在被 GPU 仿真缓解）。
3. 🕳 **人形 × 低重力**：目前仅 QUT 一篇系统工作（G1/Isaac Sim）。上半身质量占比大 → 飞行相姿态控制、跌倒恢复、手臂辅助平衡都是问题。
4. 🕳 **VLA/基础模型的重力条件适配**：没有工作研究语言条件策略在低重力下的泛化；NaVILA 式中层接口 + 低重力低层策略是可发的组合点。
5. 🔥 **跨重力泛化策略**（单策略多重力 vs 每重力一策略 vs 重力作为条件输入）——训练范式本身尚无定论。
6. 🕳 **验证手段平民化**：多数团队没有卸载台架/抛物线飞行；纯仿真的可信度论证（多仿真器 sim2sim、灵敏度分析）有方法论价值。

## 四、与你目标的映射建议

```
阶段1（现在）: MuJoCo/Isaac Lab + unitree_rl_gym/lab
   → 把 g 从 9.81 改为 1.62，跑通 G1/Go2 月面行走
   → 复现 QUT 工作（fine-tune vs scratch 对比）作为 baseline

阶段2: 差异化创新点（选一个切入）
   → A: 软接触月壤地形 + RL（接 OmniLRS 或自构颗粒地形）
   → B: 重力条件化单一策略（g 作为观测输入，1.62~9.81 连续泛化）
   → C: 跳跃/长飞行相的 Transformer 策略（复现+改进 0580）

阶段3: VLA 接入
   → NaVILA 式分层：中层语言动作 ↔ 你的低重力低层策略
   → "低重力条件下的 VLA 运动控制泛化"本身就是论文点
```
