## 第一部分：社区经验汇总（第一轮搜索结果）

### 1.1 中文社区（知乎/CSDN/公众号/技术博客）

**CSDN《强化学习拾遗——再看奖励函数》** 给出最有价值的失效分类学：

- **稀疏奖励问题** → 主线奖励太稀疏，agent 随机探索碰不到正反馈 → 辅助奖励三类：子目标奖励、塑形奖励（PBRS）、课程奖励
- **贪婪（Reward Hacking / Wireheading）**：奖励片面奖励子目标又缺制衡 → agent 反复攫取局部收益。例：导航任务在门上放奖励 → agent 在门里来回刷分不走
- **懦弱（Cowardice）**：⭐辅助惩罚项绝对值大于主线奖励 → 训练初期大量负反馈 → agent 停在原地不敢动（PitFall 效应）——**这正是人形/四足"站立不动局部最优"的理论解释**

**低成本双足实战帖（二趣网）** 给出调参顺序的实战经验：

- 奖励开启顺序很重要："先把存活奖励设固定正值让算法学会不倒 → 再加入速度项 → 最后逐步加姿态和能耗惩罚。一次全加，奖励信号过密，策略不知道优先满足哪个"
- 终止条件先宽后严：初期放宽到俯仰 45°/翻滚 35°，学会平衡再收紧——**"每走两三步就终止，机器人学不到任何有效经验"**
- 动作平滑度均值迟迟不降 = 策略靠高频抖动维持平衡 = 真机必崩
- "episode 很长但速度误差偏大 = 学会站很久不倒，但没完成任务" —— 两个指标要一起看
- `last_action` 进观测是隐式平滑技巧

**技术栈/公众号 G1-29dof 手册**给出速查表：

| 现象 | 调参方向 |
|---|---|
| 站着不动 | ↑ track_lin_vel 权重，↓ action_rate 惩罚 |
| 高频抖动 | ↑ action_rate 惩罚 |
| 容易摔倒 | ↑ flat_orientation、base_height 惩罚 |
| 外八/内八 | ↑ joint_deviation_legs 惩罚 |
| 持续转向 8–22s 累积失稳 | episode 加长到 30s 强迫学会长时稳定 |

并强调："**每次改动先保存原配置与种子，画分项奖励与 episode 长度，单变量对照；不要用加奖励权重来掩盖错误观测或关节映射**"。

**人形步态实作排查指南（humanoidai.blog）**给出"先怀疑的五件事"：接触误判、时钟不同步、零位/rigging 错、执行器限流/热降额、摩擦估计偏差——**出问题先别改全局增益，先压回到可观测可复现的层面**。

### 1.2 GitHub Issues / 英文社区

- **unitree_rl_gym Issue #80**：G1 训到 16k iter episode 长度掉头下降、130k 后全体怪异姿势——**长训后策略退化的真实案例**
- **marmotlab/APEX Issue #5**：H1 模仿训练不收敛，元凶是**网络太小（单隐层 32）**；模仿 PD 分量退火后崩溃；"换 seed 就好了"——PPO 的 seed 敏感
- **skrl Discussion #385**：mean timesteps 涨但 min 不涨、reward 中途变差
- **IsaacLab Discussion #3040**：摔倒后起身学不了——reward/termination 需要专门设计
- **IsaacLab #458**：solo12 站着不动 → `enabled_self_collisions` 配置错误
- **22kashaf-khan/ppo-checkpoint-selection**：7M 步 checkpoint 优于 10M 终点；同代码不同 seed 回报差 **3.4 倍**
- **Humanoid-Robot-MuJoCo 仓库 README**："PPO 在平台期震荡而非收敛，**较晚的 checkpoint 经常不如早的**"（17.4M 步得分 6040 < 15.1M 的 7679）；"每回合重采样指令"防止策略背答案

## 第二部分：提炼的失效模式关键词

| # | 关键词（失效模式） | 对应现象 |
|---|---|---|
| K1 | **懦弱/惩罚淹没** (cowardice, penalty dominance) | 站立不动、不敢动、零动作瘫站 |
| K2 | **Reward Hacking** | 蹬边缘借力、门口刷分、靠抖动平衡 |
| K3 | **稀疏奖励 / 探索死局** | adjust不起、跳跃/上楼梯学不会 |
| K4 | **速度-稳定冲突 / 多目标干扰** | 强化速度就摔、强化稳定就停 |
| K5 | **策略塌陷（policy collapse / late-training regression）** | 训练中途奖励跳水、步态变螃蟹 |
| K6 | **终止条件不当** | 太严苛 → 学不到东西；太松 → 学恢复歪招 |
| K7 | **配置层假学习问题** | 站都站不稳（资产/驱动/接触/自碰撞错） |
| K8 | **步态先验缺失** | 抽搐、原地碎步、周期步态出不来 |

## 第三部分：按关键词搜到的具体方法 × 目标场景

### K1 懦弱/惩罚淹没 → "站得住但不敢动"

| 方法 | 出处 | 目标场景 |
|---|---|---|
| **惩罚权重自适应（约束优化）** | iScience 2025：初始强能耗代价→零动作假死→改用**约束优化/自适应权重** | 站立→行走过渡期 |
| **ROGER**（Reward-Oriented Gains via Embodied Regulation, 2025） | 在线调奖惩比：接近约束阈值时自动降低惩罚/奖励比。真机四足**1 小时从零学会走路零摔倒** | 奖励权重不想手调 |
| **CaR / Lagrangian 约束法** | Constraints as Rewards (2025)：不写奖励函数，只写约束（如关节限位直接从 URDF 读），拉格朗日乘子自动当权重。"Not Only Rewards But Also Constraints"(2023) 已在腿足上验证 | 奖励项 >10 个、调参地狱时 |
| **奖励开启顺序** | 存活→速度→姿态/能耗逐步开（二趣网实战） | 一切新任务起手式 |
| **`only_positive_rewards` + 活着奖励** | legged_gym 标配 | 通用 |

### K2 Reward Hacking → "在骗分"

| 方法 | 出处 | 目标场景 |
|---|---|---|
| 地形边缘检测 + `feet_edge` 惩罚 | 梅花桩比赛实战 | 离散障碍地形 |
| 奖励门控（低速关 air_time） | lsqyrobot 翘腿排查表 | 平地任务异常动作 |
| **速度奖励写成 `max(1-‖v*-v‖², 0)`** | Stylized Biped AMP：这种饱和式速度奖励专门防"站着不动避风险" | 站立/行走切换 |
| 指令每回合重采样 | Humanoid-MuJoCo 仓库：防策略背答案 | 通用 |
| 分项奖励监控 + 定期看视频 | 所有经验帖 | 永远 |

### K3 稀疏奖励/探索死局 → "永远学不会"

| 方法 | 出处 | 目标场景 |
|---|---|---|
| **RSI 参考状态初始化** | DeepMimic；wbc-mjlab 自适应分 bin | 跳跃、爬楼梯、有明确成功态的技能 |
| **ET 早终止 + TC 终止课程** | Self-Imitation Learning 论文；Stanford CS224R：松终止更鲁棒、渐进收紧有失败边界 | 动态技能 |
| **步态条件化（Gait-Conditioned RL）** | 2025 论文：one-hot gait ID 路由不同奖励 → 站/走/跑单网络切换，真机 G1 验证 | 多步态共存 |
| **足步序列喂策略** | arXiv 2207.12644：只喂未来 2 步落脚点 → 无需参考轨迹全向走+爬楼 | 楼梯/离散地形 |
| **RND / 对称增广** | rsl_rl 内置 `rnd_cfg`、`symmetry_cfg` | 探索坍缩 |
| **模仿先验**（AMP/跟踪奖励） | AMASS 重定向 | 人形一切难技能 |

### K4 速度-稳定冲突 → "加 A 退 B"

| 方法 | 出处 | 目标场景 |
|---|---|---|
| **分层渐进开奖励** | 一致经验 | 一切任务 |
| **KL 退火蒸馏** | Science Robotics 2024：teacher 监督权重中途线性退到 0，学生可超越 | teacher-student 流程 |
| **D-PPO** | 权重继承 + 蒸馏/PPO 损失各半 | 感知策略训练 |
| **残差 RL** | zanshi-dev：纯 PPO 失败 → reference trot + residual 成功 | 端到端探索不动时 |
| **技能原语** | RoboCup FC Portugal：每技能独立训 + 统一接口 | 多技能任务 |

### K5 策略塌陷 → "训着训着崩了"

| 方法 | 出处 | 目标场景 |
|---|---|---|
| **checkpoint 选择而非取最终** | 多仓库实测：7M>10M、15.1M>17.4M；PPO 是平台震荡不是收敛 | 永远；≥200 episode 评估每个 checkpoint |
| **多 seed + 统计检验** | 同配置 seed 间回报差 3.4x；Welch t-test + Cohen's d | 下结论前 |
| **clip ε 衰减 + LR 衰减** | TildAlice：恒定 0.2 裁剪范围 + 策略收敛 = 1M 步后必然发散；ε 0.2→0.05、lr 3e-4→3e-5 | 长训任务 |
| **value loss 监控** | 价值发散是塌陷前兆；盯 advantage、clip fraction、explained_variance | 永远 |
| **网络容量** | APEX：单隐层 32 是 H1 学不动的元凶 |  dof 多时检查容量 |
| **退火分量检查** | APEX：模仿 PD 退火系数掉太低后纯策略撑不住 | 模仿+RL 混合训练 |

### K6 终止条件 → "学不到"或"学歪"

- **先宽后严**：初期放宽姿态/高度终止阈值（二趣网：俯仰 45°），学会平衡再收紧
- **TC**：把瞬时奖励阈值做成课程（0.75→0.5），Stanford 实验显示**突变会崩，渐进能活**
- **摔倒是数据不是终点**：摔倒后起身（get-up）要单独当任务训（IsaacLab #3040），别把 reset 当遮羞布
- `time_out` 与摔倒分开记，`send_timeouts` 给 PPO 做 bootstrap

### K7 配置层假学习问题 → "站都站不稳"

按序排查：**自碰撞开关 → 关节零位/rigging → actuator 配置（Implicit vs DCMotor）→ 接触传感器 link 名 → 控制频率与奖励累计量纲**。法则：平地学不会 = 配置错，不是奖励错。

### K8 步态先验缺失 → "抽搐/碎步/周期步态出不来"

- **相位时钟进观测**（人形几乎必需）+ **DS/SS 触地掩码奖励**（humanoid-gym/Booster）
- 站立 gait 时 **gait cycle 置零**，实现站↔走无缝切换（Booster 技巧）
- 指令变化时**截断观测历史序列**（Booster 细节：防不切实际的预测）
- 参考正弦步态 / RSI / 残差基底

## 第五部分：概念澄清（补充问答）

### 5.1 塑形 / 课程 / 辅助奖励的区别

**辅助奖励**是总称：主线奖励（任务成败信号，如"到达终点""跟上指令速度"）之外的所有奖惩项，目的都是把稀疏信号变稠密、给 agent 指路。CSDN 原文的三类：

| 类别 | 含义 | 腿足实例 |
|---|---|---|
| 子目标奖励 | 按对主线的贡献度分配奖惩（鼓励型/回避型） | `feet_air_time`、`lin_vel_z` 罚——legged_gym 大多数项 |
| 塑形奖励 | 给无信号状态加信号。规范形式 PBRS：`F=γΦ(s')−Φ(s)`，不改最优策略；简化变体"离目标越近罚越少"无最优性保证 | 朝向引导、高度差整形 |
| 内驱奖励 | 奖励未见过状态/动作促探索 | RND/ICM（rsl_rl 内置 `rnd_cfg`） |

**课程**是正交维度：不改"奖励什么"，而是随训练进度改难度/权重——地形等级、指令范围、奖励权重、终止阈值都可做课程。塑形解决"信号有没有"，辅助奖励是手段集合，课程解决"什么时候多难"。

### 5.2 按行为动态增减奖励项的四档方法

| 档 | 机制 | 代表方法 |
|---|---|---|
| (a) 固定日程 | 按步数切换，不看行为 | Isaac Lab `modify_reward_weight`；legbot_lab 惩罚项按期移除 |
| (b) 条件激活 | 按当前行为模式逐项生效 | **Gait-Conditioned RL**：one-hot gait ID 路由整套步态奖励，站/走/跑互不干扰（真机 G1）；Booster 站立时 gait cycle 置零 |
| (c) 性能触发 | 达标才晋级/变权 | 指令课程（tracking>80% 扩范围）；**CHRL** 自动调指令范围+奖励系数+环境难度；自适应终止阈值校准 |
| (d) 连续自适应 | 权重本身是可学变量 | **ROGER** 按约束违反度调奖惩比；**CaR/Lagrangian** 乘子即权重；iScience 自适应代价；DreamWaQ AdaBoot |

工程启示：手动调权=(a)；不想写奖励逻辑=(b)；"达标才晋级"=(c)；完全不想碰权重=(d)。
